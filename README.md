## Overview

ChowKick synthesizes kick drums using physically inspired banded-waveguide modeling tuned to emulate the tonal characteristics of classic drum machine kicks, with pitch envelope, click, and sub control.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **ChowKick** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Banded Waveguide** | Physical waveguide synthesis inspired by drum machine circuits |
| **Pitch Envelope** | Exponential pitch drop with start frequency, decay, and end pitch |
| **Click Layer** | Transient click synth blended with the waveguide body |
| **Sub Boost** | Sub-frequency enhancer for extended low-end weight |
